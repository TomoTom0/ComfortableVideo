# v1.2.1 (2026-11-11)

## Bug Fixes

- TTFC快適モード解除時に動画表示が消える不具合を修正。プレースホルダー要素による確実な位置復元、TTFC用コンテナ検索フォールバック、復元後のセーフティチェックを追加
- findTTFCPlayerContainerのセレクタをdiv限定に変更し、インライン要素誤検出を防止 (PR#16)
- プレースホルダークリーンアップをisTTFC()外に移動し、全サイトで残存プレースホルダーを確実に削除 (PR#16)
- SVGコントロールボタンの数字がつぶれる不具合を修正。巻き戻し・早送りボタンのSVGテキスト（10/30）にstroke="none"を追加し、アウトラインによるつぶれを解消 (PR#15)
- Prime Videoで快適モード中に動的に生成された字幕オーバーレイが背面に回る不具合を修正。`startPrimeCaptionsObserver` の移動経路にも `comfort-mode-exempt` クラスの付与を追加し、z-index制限による字幕の背面化を防止

## Internal Improvements

- v1.2.0.mdの見出しをUnreleasedからv1.2.0に修正 (PR#14)
- デプロイスクリプト参照をrsync.shからdeploy.shに統一し、古いrsync.shを削除 (PR#15)
- ビルド・デプロイ等のタスク実行をpnpm runからmise（.mise.toml）に移行 (PR#15)
- v1.2.0 CHANGELOGとドキュメントから未実装機能（Prime Video広告自動ミュート）の誤記載を削除
