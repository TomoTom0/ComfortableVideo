# 権限の根拠説明

このドキュメントでは、Comfortable Videoが正常に機能するために各権限が必要な理由を説明します。

## 宣言されている権限

### 1. activeTab

**Manifest宣言:**
```json
"permissions": ["activeTab"]
```

**必要な理由:**
`activeTab`権限は、Comfortable Videoの中核機能に不可欠です。この権限により以下が可能になります：

1. **動画要素の検出** - ユーザーが快適モードを有効化した際に、現在のページ上の動画要素を検出
2. **CSSスタイルの変更** - 動画表示を最大化し、周囲のページ要素を非表示にする
3. **カスタムコントロールの注入** - 拡張された動画再生管理のためのカスタムコントロールを追加
4. **元の状態への復元** - 快適モードを無効化した際に元の状態に戻す

**ユーザーコントロール:**
この権限は、ユーザーが以下の方法で明示的に拡張機能を有効化した場合にのみアクセスを許可します：
- 右クリックコンテキストメニューの選択
- 拡張機能アイコンのクリック
- プレーヤー内ボタンのクリック（対応サイト）

**データ取り扱い:**
データの抽出や送信は行いません。この権限は、快適な視聴体験を実現するためのDOM操作のみに使用されます。

**検討した代替案:**
`<all_urls>`ホスト権限を使用すると過度に広範囲になります。`activeTab`は、ユーザーが明示的に呼び出した場合にのみアクセスを許可することで、プライバシーを尊重しながら必要な機能を提供します。

---

### 2. contextMenus

**Manifest宣言:**
```json
"permissions": ["contextMenus"]
```

**必要な理由:**
`contextMenus`権限により、拡張機能の機能への便利なアクセスが可能になります：

1. **「快適動画モードを切り替え」メニュー項目の追加** - ブラウザの右クリックメニューに追加
2. **動画固有のメニュー項目の提供** - 動画要素を直接右クリックした際の専用メニュー
3. **ユーザー体験の向上** - 機能を有効化する複数の方法を提供

**ユーザーコントロール:**
ユーザーは、ツールバーアイコンのみを使用したい場合、拡張機能のオプションページでコンテキストメニュー項目を無効化できます。

**データ取り扱い:**
データ収集はありません。この権限はメニュー項目の追加とクリックイベントの処理のみに使用されます。

**検討した代替案:**
拡張機能アイコンのみに頼ることも可能ですが、利便性が低下します。コンテキストメニュー統合は、コンテンツ変更型拡張機能の標準的なUXパターンです。

---

### 3. storage

**Manifest宣言:**
```json
"permissions": ["storage"]
```

**必要な理由:**
`storage`権限は、ユーザー設定をローカルに保存するために必要です：

1. **ブラウザセッション間での設定の永続化**
2. **カスタマイズ設定の保存:**
   - ホバー検出時間（コントロール表示までの待機時間）
   - コントロール無効化時間（動画エリアを離れてから非表示になるまでの時間）
   - 終了ボタンの透明度
   - 有効/無効サイト
   - コンテキストメニューの表示設定

**データ取り扱い:**
- 全てのデータは`chrome.storage.local`を使用してローカルに保存
- **Googleサーバーへの同期なし**（`chrome.storage.sync`は使用していません）
- **外部への送信なし**
- **トラッキングや分析なし**

**保存されるデータ型:**
```javascript
{
  hoverDetectionTime: number,      // ミリ秒
  controlsDisableTime: number,     // ミリ秒
  showContextMenu: boolean,
  showVideoContextMenu: boolean,
  showInlineButton: boolean,
  pausedControlsEnabled: boolean,
  enabledSites: {
    youtube: boolean,
    primeVideo: boolean,
    allSites: boolean
  },
  exitButtonOpacity: number        // 0-100
}
```

**ユーザーコントロール:**
ユーザーは、オプションページの「デフォルトに戻す」ボタンを使用して、保存された全ての設定をリセットできます。

**検討した代替案:**
設定を永続化しない場合、ユーザーはブラウザを起動するたびに設定を再構成する必要があり、ユーザー体験が大幅に低下します。

## Content Scripts

**Manifest宣言:**
```json
"content_scripts": [{
  "matches": ["<all_urls>"],
  "js": ["content.js"],
  "css": ["content.css"],
  "run_at": "document_end"
}]
```

**必要な理由:**
Content scriptsは、ウェブページに必要な機能を注入します：

1. **ページ読み込み時の動画要素の検出**
2. **有効化イベントのリスニング**（コンテキストメニュー、アイコンクリック）
3. **快適視聴モードのCSSスタイルの適用**
4. **マウス位置に基づくコントロール表示の管理**
5. **キーボードショートカットの処理**（ESCで終了）

**スコープ:**
`<all_urls>`は広範囲に見えますが、content scriptは：
- 有効化されるまでバックグラウンドで受動的に動作
- ユーザーが明示的に快適モードを有効化した場合のみページを変更
- ユーザーのサイト別設定を尊重（サイトごとに無効化可能）

**データ取り扱い:**
- ページからのデータ抽出なし
- 外部サーバーとの通信なし
- 視覚的表示のためのDOM操作のみ

**`<all_urls>`を使用する理由:**
ユーザーは、あらゆる動画ホスティングウェブサイトで快適モードを使用したい可能性があります。特定のドメインに限定すると、以下のサイトで拡張機能が動作しなくなります：
- セルフホスト型の動画プラットフォーム
- 社内の企業研修サイト
- 新興の動画プラットフォーム
- 地域の動画サービス

---

## Web Accessible Resources

**Manifest宣言:**
```json
"web_accessible_resources": [{
  "resources": ["content.css"],
  "matches": ["<all_urls>"]
}]
```

**必要な理由:**
CSSファイルは、Content Security Policy (CSP)制限のあるページに適切に適用されるために、web accessibleである必要があります。これにより以下が保証されます：

1. **厳格なCSPを持つ全てのサイトでスタイルが動作**
2. **適切なCSSカスケードと詳細度**
3. **異なる動画プラットフォーム間での一貫した視覚的外観**

**セキュリティ:**
- CSSファイルのみを公開（JavaScriptは含まず）
- CSSはコードを実行したりデータにアクセスしたりできません
- Chrome拡張機能でカスタムスタイルを適用する標準的な方法

---

## まとめ

全ての権限は：
- **中核機能に必要**
- **必要最小限にスコープ設定**
- **プライバシーを尊重**（データ収集や送信なし）
- **ユーザーが制御可能**（機能を無効化する設定あり）

拡張機能は、以下によりChrome Web Storeのベストプラクティスに従っています：
- 広範なホスト権限の代わりに`activeTab`を使用
- データはローカルにのみ保存（同期ストレージは使用しない）
- 各権限の明確な説明を提供
- 動作をカスタマイズするユーザーコントロールを提供
