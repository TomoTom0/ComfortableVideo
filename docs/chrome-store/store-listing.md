# Chrome Web Store掲載情報

## 拡張機能名
Comfortable Video

## カテゴリ
生産性

## 短い説明（132文字以内）
動画をフルスクリーンの快適モードで視聴。スマートコントロールで邪魔な要素を非表示にし、動画そのものに集中できます。

## 詳細な説明

Comfortable Videoは、動画をブラウザウィンドウ全体に最大化し、コントロールをインテリジェントに管理することで、集中を妨げない動画視聴体験を提供するChrome拡張機能です。

### 主な機能

**全画面動画表示**
動画をブラウザウィンドウ全体に拡大表示します。元の縦横比は維持されるため、歪みはありません。ウィンドウサイズの変更にも自動対応します。

**スマートなコントロール管理**
動画上にマウスがあっても、コントロールは非表示のまま。意図しない操作で集中が途切れることはありません。コントロールは必要な時だけ表示されます：
- 動画下部20%の領域に2秒間マウスを置く
- 下部エリアをクリックして即座にアクセス
- マウスを離して3秒後に自動非表示

**確実な前面表示**
高度なz-index管理により、広告、ポップアップ、サイドバーなどのページ要素が動画を遮ることはありません。

**直感的な操作**
- 開始：右クリックメニューまたは拡張機能アイコン
- 終了：ESCキー、終了ボタン（右下）、または右クリックメニュー
- 完全にカスタマイズ可能な設定

**カスタム動画コントロール**
追加のコントロールボタンオーバーレイ：
- 再生/一時停止トグル
- 30秒前後へのシーク
- ミュート/ミュート解除トグル
- 全ての操作に視覚的フィードバック

**プライバシー重視**
全ての設定はデバイスにローカル保存。データ収集なし、外部サーバーなし、トラッキングなし。

### 対応サイト

**自動起動（主要サイト）:**
- YouTube
- Amazon Prime Video
- 東映特撮ファンクラブ (TTFC)
- TVer
- Netflix

**手動起動（その他のサイト）:**
上記以外のサイトでも、右クリックメニューまたは拡張機能アイコンから起動できます。HTML5動画プレーヤーを使用するほぼ全てのウェブサイトで動作します。

### こんな方に最適

- UI要素に邪魔されずに長時間コンテンツを視聴したい
- オンライン学習や教育動画の視聴
- 最大限の没入感で映画をストリーミング視聴
- 動画コンテンツだけに集中したいあらゆる場面

### 技術的特徴

- Chrome Extension Manifest V3準拠
- 信頼性のためのTypeScript実装
- 効率的なCSSベースのイベント管理
- 自動ウィンドウ調整を備えたレスポンシブデザイン
- 多言語サポート（日本語、英語、中国語）

### ユーザーレビュー

この拡張機能は、よくある動画視聴時の不満を解決します：邪魔な広告、気が散るコメント欄、誤ってコントロールを表示させてしまうことによる集中の妨げ。動画本来のあるべき姿、没入感と途切れのない体験を提供します。

## スクリーンショット説明

### スクリーンショット1：YouTube快適モード
YouTubeの動画が快適モードで最大化され、クリーンで集中を妨げないインターフェースを表示。

### スクリーンショット2：コントロール表示
動画下部にマウスを置いた際にコントロールが表示される、スマートコントロール機能のデモ。

### スクリーンショット3：カスタムコントロールオーバーレイ
動画上にオーバーレイ表示されるカスタムコントロールボタン（再生/一時停止、シーク、ミュート）。

### スクリーンショット4：オプションページ
ホバータイミング、有効サイト、表示設定などのカスタマイズオプションを示す設定ページ。

### スクリーンショット5：コンテキストメニュー統合
クイックアクセスのための「快適動画モードを切り替え」オプションを含む右クリックコンテキストメニュー。
