# Chrome Web Storeコンプライアンスチェックリスト

このドキュメントは、Comfortable VideoがChrome Web Storeの全ての要件とポリシーを満たしていることを保証します。

## プログラムポリシーへの準拠

### ✅ 単一目的
- **ポリシー:** 拡張機能は単一の明確な目的を持つ必要がある
- **準拠状況:** Comfortable Videoは一つの目的を持つ：集中を妨げない動画視聴を提供
- **証拠:** 全ての機能（全画面表示、スマートコントロール、カスタムオーバーレイ）がこの単一の目標に貢献

### ✅ 権限
- **ポリシー:** 必要な権限のみを要求し、明確な根拠を示す
- **準拠状況:**
  - 4つの権限のみ要求（activeTab, contextMenus, scripting, storage）
  - 各権限に文書化された根拠がある
  - content_scriptsは主要サイト限定、その他は`scripting`APIで動的注入
- **ドキュメント:** `permissions-justification.md`を参照

### ✅ ユーザーデータとプライバシー
- **ポリシー:** データ収集と使用を明確に開示する
- **準拠状況:**
  - データ収集なし
  - 外部へのデータ送信なし
  - ローカルストレージのみ使用
  - プライバシーポリシーを完全に文書化
- **ドキュメント:** `privacy-policy.md`を参照

### ✅ 禁止製品
- **ポリシー:** マルウェア、アドウェア、欺瞞的な動作を含まない
- **準拠状況:**
  - 広告なし
  - トラッキングなし
  - 暗号通貨マイニングなし
  - 難読化コードなし
  - オープンソース：完全な透明性

### ✅ コンテンツポリシー
- **ポリシー:** 違法、有害、または不適切なコンテンツなし
- **準拠状況:** 拡張機能は視覚的表示のみを変更；メディアコンテンツの作成/ホスト/変更は行わない

## 技術要件

### ✅ Manifest V3
- **要件:** Manifest V3を使用する
- **準拠状況:** `manifest.json`で`"manifest_version": 3`を宣言
- **Service Worker:** バックグラウンドページではなく、background service workerを使用

### ✅ コード品質
- **要件:** コードは読みやすく、難読化されていない必要がある
- **準拠状況:**
  - TypeScriptソースがGitHubで利用可能
  - コンパイルされたJavaScriptは読みやすい（minify化されていない）
  - 明確な変数名と構造
  - ビルド出力にコメントが保持されている

### ✅ セキュリティ
- **CSP準拠:** インラインスクリプトなし、適切なCSPヘッダー
- **eval()なし:** eval()やnew Function()の使用なし
- **安全なAPI:** Chrome Extension APIのみ使用（リモートコード実行なし）
- **HTTPS のみ:** 全ての外部リソース（もしあれば）はHTTPS経由

### ✅ 国際化
- **要件:** 複数言語のサポート
- **準拠状況:**
  - `_locales/`経由のi18nサポート
  - 3言語：日本語、英語、中国語
  - 全てのUI文字列が`chrome.i18n.getMessage()`を使用

## レビュー対応プラン

Chrome Web Storeのレビュアーが説明を求めた場合：

### よくある質問と準備済みの回答

**Q: content scriptの対象サイトが限定されているが、他のサイトでも動作するか？**
A: `permissions-justification.md`を参照 - 主要サイト（YouTube、Amazon Prime Video、TVer、Netflix）では自動起動。それ以外のサイトでは`scripting`権限を使い動的注入するため、右クリックメニューまたはアイコンクリックで起動可能。

**Q: どのようなデータが収集されるか？**
A: ゼロ。`privacy-policy.md`を参照 - 全ての設定はchrome.storage.localを使用してローカルに保存。外部送信なし。分析なし。

**Q: なぜactiveTabが必要か？**
A: `permissions-justification.md`を参照 - 動画要素を検出し、快適視聴のためにCSSを変更するために必要。ユーザーが明示的に拡張機能をトリガーした場合のみ有効化。

**Q: サードパーティコードは？**
A: なし。`third-party-disclosure.md`を参照 - 全てのコードがオリジナル。ビルドツール（TypeScript、Sass）は開発時に使用されるが、パッケージには含まれない。
